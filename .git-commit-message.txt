fix(api): Handle 401 errors dengan auto session refresh

- Session timeout tidak di-handle dengan baik  
- Client error logger mencatat semua 401 sebagai error
- Database error_logs penuh dengan false-positive

SOLUSI:
1. Enhanced clientErrorLogger.ts:
   - Skip logging 401 untuk auth endpoints
   - Filter expected authentication errors
   - Database error logs lebih bersih

   - Auto-detect session expired (401)
   - Auto-refresh session via /api/auth/session
   - Auto-retry request setelah refresh
   - Auto-redirect ke login jika refresh gagal
   - Lock mechanism untuk prevent duplicate refresh

3. Updated attendance page:
   - Import dan gunakan authFetch
   - Better error handling dengan null check
   - Better user experience
